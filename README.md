# Stochastic Hill Climbing

A Python GUI project that demonstrates the Stochastic Hill Climbing algorithm for path finding.

## Features
- User-defined Start and Goal states
- User-defined state values and neighbors
- Random selection of better neighbors
- Step-by-step visual path
- Goal state detection
- Interactive Tkinter GUI

## Technologies
- Python
- Tkinter
- Random Module

## Outcome
The system visually demonstrates how Stochastic Hill Climbing searches for a better path and reaches the goal state.
